# 日记

记录每天的工作与生活琐事，按月归档。**正文是加密的**：仓库和网站里只有密文，打开某个月份、输入密码后才会在你的浏览器里本地解密显示。

## 平时怎么用（两步）

不想敲命令的话，项目根目录有三个 bat，**双击即可**：

| 文件 | 作用 |
|---|---|
| `写日记.bat` | 创建今天的条目（自带骨架）并在 VS Code 打开；已有条目不会被改动 |
| `提交日记.bat` | 加密 → 提交 → 推送 |
| `新电脑初始化.bat` | 换电脑时双击一次：装依赖、输密码、解密全部日记 |

对应的命令行写法：

```bash
npm run diary          # 1. 追加今天的条目，并自动在 VS Code 打开当月文件，直接写（明文，随便改）
npm run diary:push     # 2. 加密 → 提交 → 推送，一步到位
```

- `npm run diary -- 串口调试` 标题后带主题；`npm run diary -- 2026-08-01 月初计划` 补写指定日期；加 `--no-open` 不打开编辑器
- `npm run diary:push -- 补写上周` 自定义提交说明；默认是 "日记 YYYY-MM-DD"
- 改以前的日记：直接编辑 `private/diary/<年>/<月>.md`，然后同样 `npm run diary:push`
- 排版规则：条目按日期 **01 → 31** 排列（越往下越新），条目之间一个空行；`npm run diary` 每次运行都会自动整理，补写的日期会插到正确位置；只想整理不新增用 `npm run diary -- --format`
- 正文里**单个换行就是换行**，逐行写即可，不用像普通 Markdown 那样在行尾加两个空格或空一行
- 日记和其他笔记一起改时，正常 `git add . && git commit` 也行：提交钩子会把有改动的月份自动加密并带上
- 只改了日记却用普通 `git commit`：git 会因为暂存区一开始为空而不生效，钩子会提示你再 commit 一次（这是 git 的限制，所以推荐 `diary:push`）

## 目录约定

```
private/                  ← 整个目录已 gitignore，永远不要提交
├── .password             ← 日记密码，一行明文；钩子和 lock/unlock 脚本会自动读取
└── diary/2026/08.md      ← 明文，一个月一个文件，一天一个二级标题

docs/diary/               ← 密文，提交到仓库、发布到网站
├── README.md             ← 本页（公开）
└── 2026/08.md            ← 自动生成，只含标题和密文
```

- 左侧边栏按年、月**自动**生成，不用改 `config.js`
- 页面的**一级标题会公开显示**（当侧边栏文字用），别把隐私写在一级标题里

## 手动命令

```bash
npm run diary:lock            # 手动加密全部月份（有 private/.password 时不会再问密码）
npm run diary:unlock          # 换电脑时：用密码把 docs/diary 的密文还原到 private/diary
npm run diary:unlock -- --force   # 覆盖已存在的明文
```

## 多台电脑

每台电脑各有一份明文（`private/`），通过仓库里的密文同步：

- **新电脑首次**：`git clone` → `npm install` → `npm run diary:init`（输一次密码：写入密码文件、启用钩子、解密全部月份）
- **之后每次 `git pull`**：钩子会自动把这次拉下来有变化的月份解密到 `private/diary`，不用手动操作
- **保护规则**：如果本机某个月份有还没提交的改动，pull 时不会覆盖它，而是提示你先提交（或备份后 `npm run diary:unlock -- --force`）
- 建议习惯：**改日记前先 `git pull`，改完就提交**，两台电脑同时改同一个月份就不会打架

## 关于密码与安全

- 密码只存在你电脑上的 `private/.password`，不在仓库、不在网站；忘了且文件也丢了就真的解不开
- 密文是公开的，别人可以下载后离线猜密码。**密码越短越容易被撞出来**，16 位以上随机密码才算稳妥
- 加密方式：PBKDF2-SHA256（30 万次）派生密钥 + AES-256-GCM，实现见 `docs/.vuepress/diaryCrypto.js`
- 解锁后密码只记在当前浏览器标签页（sessionStorage），关掉即失效；页面上"锁定"可立即清除
- 日记里如果要放图片，图片文件本身不会被加密，放到 `docs/.vuepress/public/` 并用绝对路径引用
- 跳过一次钩子：`git commit --no-verify`（但那样网站上的日记就不会更新）

## 写法示例

`npm run diary` 新建的条目自带下面这个骨架：**用 `###` 分块 → 每块列要点 → 最后一段总结**。用不到的块删掉就行，块名也可以随便改。

```markdown
# 2026年08月日记

## 08-28 星期五 串口仪器接口调试

### 反思
今天遇到的坑：

1. 粘包问题，改为按帧头帧尾切分
2. 串口超时要设短一点

### 项目
1. 手机自动化测试工具跑通了

### 总结
> 明天先把 esp32 烧录器的可行性测一下

## 08-29 星期六

- 休息
```

- 列表直接写 `1. `，前面空一行；不要整段包在 `>` 里，`>` 留给总结更醒目
- 排序脚本只认 `## MM-DD` 这一层，`###` 小标题会跟着当天一起走
